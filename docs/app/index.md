# Config builder

!!! info "How to run locally"

    ```bash
    cd app
    npm install
    npm run dev
    ```

    That serves the builder at <http://localhost:5173/AbilityEditor/app/>, reading
    `docs/schema.json` straight from the working tree — so it always reflects whatever
    `.scripts/generate-docs.ps1` last produced.

The published version lives at
[boundir.github.io/AbilityEditor/app/](https://boundir.github.io/AbilityEditor/app/).
